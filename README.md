# BioWatch India - Digital Biodiversity Monitoring

A responsive web application for monitoring threatened species and conservation efforts across India.

## Features Included
- **Live Search & Multi-Criteria Filtering**: Filter species by keyword, category (Mammals, Birds, Reptiles, Plants), and IUCN Red List status.
- **Interactive Map**: Dynamic regional surveillance desk with active tracking stats, camera traps, and local wildlife data for Uttarakhand, Assam, West Bengal, Karnataka, and Gujarat.
- **Citizen Science Sighting Log**: Field observation reporting modal with client-side persistence in `localStorage`.
- **Synthesized Wildlife Audio**: Web Audio API-based animal calls (Bengal Tiger, Asian Elephant, Peafowl, Rhino, and Forest Ambiance) playable without external audio assets.
- **Night Patrol Theme**: Dark mode toggle with persistent setting.
- **Dataset Export**: Dynamic CSV export of all monitored species.

## How to Run
Simply open `index.html` in any modern web browser. No server setup or external dependencies required.
